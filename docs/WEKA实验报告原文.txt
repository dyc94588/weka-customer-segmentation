Experiment 1: Data PreprocessingObjective: Load data, perform normalization, and identify key features.Steps:1.Launch WEKA GUI:Open the WEKA software and click the Explorer button on the main interface. This will open the main working interface for data exploration in WEKA.2.Open the data file:In the Preprocess tab, click the Open file... button.In the pop-up file browser, locate and select your dataset file Online_Retail.csv.

The Attributes list on the left shows all attribute names. The summary statistics on the right include the type of each attribute, missing values, distribution histograms, and more.

Apply the Normalize Filter:Click the Choose button at the top right of the interface (under the Filter area) to expand the filter tree.Navigate to unsupervised -> attribute -> Normalize. This filter will perform min-max normalization on all numeric attributes.Click the Apply button. WEKA will immediately apply normalization to the data.

Perform Feature Selection (Using Information Gain):Still on the Preprocess tab, click on the Select attributes tab at the top left.Evaluator: Click the Choose button and select InfoGainAttributeEval under Attribute Evaluator.Search Method: Click the adjacent Choose button and select Ranker.Configure Parameters: In Attribute selection mode, select Use full training set.Execute: Click the Start button. WEKA will begin calculating the information gain value for each attribute.

Experiment 2: Comparison of classification algorithmsObjective: To compare the classification performance of J48, naïve Bayes, and KNN using 10-fold cross-validation.Steps:1.Switch to the Classify tab:In WEKA Explorer, click the Classify tab at the top.2.Select the classifier and configure:Click the Choose button to expand the list of classifiers.a. Test the J48 Decision Tree:Select trees-> J48.Click the text next to the classifier box to open the parameter configuration window.Confirm or set a parameter, such as a confidenceFactor of 0.25.Click OK.b. Test Naive Bayes:Select bayes-> NaiveBayes.Usually use the default parameters.c. Test KNN (IBk):Choose lazy-> IBk.Click the text next to the classifier box to open the parameter configuration window.Set the value of KNN (parameter K) to 10.Click OK.3.Set up test options:In the Test options area, select Cross-validation and set Folds to 10.4.Select the target attribute (Class):Click the Target Attribute dropdown menu below the Classify area and select CustomerValue as the category we want to predict.5.Run the experiment and record the results:Make sure you have selected the correct classifier (e.g. J48 first).Click the Start button. WEKA will run 10-fold cross-validation.

Experiment 3: Cluster AnalysisObjective: Use the K-Means algorithm to divide customers into 3 groups and analyze the characteristics of each group.Steps:1.Switch to the Cluster tab:In WEKA Explorer, click the Cluster tab at the top.2.Select and configure the clustering algorithm:Click the Choose button and select simpleKMeans.Click the text next to the algorithm box to open the configuration window.Set the number of clusters (K): Set the numClusters parameter to 3.Distance metric: Ensure that distanceFunction is set to EuclideanDistance.Other parameters can remain at default (e.g., maxIterations=500).Click OK.3.Set clustering options:In Cluster mode, select Use training set. Since we are performing unsupervised learning on the entire dataset, there is no separate test set.4.Ignore class attribute (important!):Click the Ignore attributes button right below.In the popup window, select the CustomerValue attribute and click the > button to add it to the ignore list. This step is crucial because it ensures that clustering is based on behavioral features rather than known labels; otherwise, the clustering would lose its unsupervised discovery meaning.Click OK.5.Run the clustering:Click the Start button to run the K-Means algorithm.

6.Visualizing Clustering Results:In the results list (on the left), right-click on the clustering result you just ran (for example, simpleKMeans -N 3 ...).Select Visualize cluster assignments.This will open a scatter plot window. You can adjust the drop-down menus for the X-axis and Y-axis to choose different attributes to observe the separation of clusters (for example, select TotalAmount for the X-axis and ActiveDays for the Y-axis).
