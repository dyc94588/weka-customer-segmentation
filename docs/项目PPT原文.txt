--- Slide 3 ---
Dataset Description
Basic Dataset Information:
Data Source: Simulated retail transaction data
Instances: 500 customer records
Attributes: 10 behavioral features
Data Types: 5 numerical + 5 categorical
Key Attributes Description:
TotalAmount: Total spending amount (Numerical, Ratio)
OrderCount: Number of orders (Numerical, Ratio)
ActiveDays: Active days (Numerical, Ratio)
ProductVariety: Product diversity (Numerical, Ratio)
Country: Customer country (Categorical, Nominal)
CustomerValue: Customer value label (Categorical, Ordinal)
Data Quality Assessment:
Missing values: None
Data consistency: Logically verified
Data distribution: Relatively uniform across attributes

--- Slide 4 ---
Data Preprocessing
Data Preprocessing Workflow:
1. Data Cleaning
• Missing Value Detection: No missing values
• Outlier Handling: Retain reasonable business values
2. Data Transformation
• Normalization: Min-Max Scaling
• Formula: X_normalized = (X - X_min) / (X_max - X_min)
3. Feature Selection
• Method: Information Gain Evaluation
• Result: Key features identified - ActiveDays, TotalAmount
Preprocessing Benefits:
• Improved algorithm performance and interpretability
• Reduced computational complexity
• Enhanced model stability

--- Slide 5 ---
Association Analysis
Association Rule Mining Method:
• Algorithm Selection: Apriori Algorithm
• Parameter Settings:
- Minimum Support: 0.1 (10%)
- Minimum Confidence: 0.7 (70%)
- Maximum Number of Rules: 10
Discovered Key Rules:
Rule 1: High Activity → High Spending
• Support: 15%, Confidence: 85%, Lift: 2.1
Rule 2: Multiple Category Purchases → High Customer Value
• Support: 12%, Confidence: 78%, Lift: 1.9
Rule Evaluation Metrics:
• Support: The prevalence of the rule
• Confidence: The reliability of the rule
• Lift: The strength of the rule's association

--- Slide 6 ---
Category -Methodology
Comparative Study of Classification Algorithms:
1. J48 Decision Tree (C4.5 Algorithm)
• Advantages: High interpretability, handles mixed data types
• Parameters: Confidence factor = 0.25, minimum leaf nodes = 2
2. Naive Bayes Classifier
• Advantages: High computational efficiency, suitable for high-dimensional data
• Assumption: Feature conditional independence
3. K-Nearest Neighbors (KNN)
• Advantages: No training required, suitable for multi-class classification
• Parameters: K = 10, Distance metric = Euclidean distance
Model Evaluation Method:
• Validation Method: 10-fold cross-validation

--- Slide 7 ---
Category - Results
Result Analysis:
• KNN algorithm has the highest accuracy (94.8%)
• Naive Bayes has the fastest training speed
• J48 decision tree has the best interpretability
Business Insights:
• Customer value prediction is highly feasible
• Behavioral characteristics have strong predictive power for customer value

--- Slide 8 ---
Category - Model Interpretation
Model Structure:
• Root Node: AvgOrderValue > 0.568
• Depth: 4 layers, Number of Leaf Nodes: 8
• Complexity: Moderate, easy for business understanding
Key Business Rules:
Rule 1: If average order value > 0.568 and active days > 45 → High-value customer
Rule 2: If average order value <= 0.568 but order frequency > 0.1 → Medium-value customer
Business Application Value:
• Provides the sales team with clear customer identification criteria
• Supports precise marketing resource allocation decisions
• Enables quantitative evaluation of customer value

Clustering - Methods and Results
K-Means Clustering Analysis:
Parameter Configuration:
• Number of clusters: K=3 (determined based on the elbow method)
• Distance metric: Euclidean distance
• Maximum iterations: 500
• Initialization method: Random initialization
Clustering Quality Evaluation:
• Silhouette coefficient: 0.68 (well-separated)
• SSE value: significantly decreasing trend
• Inter-cluster distance: clearly separated
